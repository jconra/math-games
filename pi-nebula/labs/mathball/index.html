Mathball Lab

The arena game's rule sets, in the order the game climbs them, and the levels built from them: each level takes its goals' rules from a range of the sets (the grid below), and a crew member starts at the level that suits them and moves up as they get balls right. Each set shows its level's example court from above: four goals a round there could start with, eight balls the ports could shoot out, and which goals each ball fits. Drag a set (or use its arrows) to change the order, then press Copy the order and paste the line it gives over the ORDER line in pi-nebula/src/mathball/ladder.js. A set dragged below the line marked Left out is left out of the game.
