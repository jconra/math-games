Mathball Lab

The arena game's rule sets, in the order the game climbs them: a crew member starts at the first that suits them and moves up as they get balls right. Each shows an example court from above: the four goals' rules at the start of a round, eight balls the ports could shoot out, and which goals each ball fits. Drag a set (or use its arrows) to change the order, then press Copy the order and paste the line it gives over the ORDER line in pi-nebula/src/mathball/ladder.js. A set dragged below the line marked Left out is left out of the game.
